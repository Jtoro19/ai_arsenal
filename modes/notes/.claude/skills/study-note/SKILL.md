# Study note

Produce one Markdown note in the vault from the given material.

## Steps
1. Identify the topic and the single concept the note should capture. One note per concept.
2. Search the vault first; prefer updating an existing note over duplicating.
3. Write the note in English with this shape:
   - Frontmatter: title, tags, date.
   - A one-line summary.
   - Key points as short bullets, in your own words (no copied paragraphs).
   - A "Commands" or "Examples" section when relevant, in fenced code blocks.
   - "See also" with [[wikilinks]] to related notes.
4. Keep it scannable: short sections, no walls of text.

## Rules
- Plain Markdown only; paraphrase, never copy long passages.
- Link related notes with [[wikilinks]].
- Do not act outside the vault.
