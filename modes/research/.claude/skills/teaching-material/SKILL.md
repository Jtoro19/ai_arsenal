# Teaching material

Produce clear, example-driven material for newcomers.

## Shape
- State the learning goal in one line and the prerequisites.
- Explain the concept with a concrete example before any abstraction.
- Add a short hands-on exercise with expected output, so the learner does, not just reads.
- End with a recap and pointers to go deeper.

## Rules
- Accurate first: do not oversimplify into something wrong; cite sources.
- Build section by section; keep each section self-contained.
- Written material in English (repo convention); explain in Spanish if asked.
- For security topics, keep examples within authorized labs and coursework.
