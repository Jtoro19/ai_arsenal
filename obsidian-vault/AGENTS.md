# Mode: notes

Working inside an Obsidian Markdown vault.

- All notes are plain Markdown; never introduce proprietary formats.
- Write note content in English (filenames, headings, body).
- One note per concept; link related notes with [[wikilinks]].
- Search before creating; prefer editing an existing note over a near-duplicate.
- When turning a lab session or command log into a writeup, use this structure:
  Context, Steps (commands + what each did), Findings, Remediation, References.
- Keep frontmatter minimal: title, tags, date.
- In notes mode, do not run or modify anything outside this vault.
